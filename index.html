    捏泡泡

    一台长在网页里的 8-bit 游戏机：内置开源自制游戏；自己的 .nes / .zip 可以存进「卡带架」，只保存在你本机浏览器里，不上传。

    怎么玩 / 按键 / 版权说明

    键盘：默认 玩家1 = 方向键移动 · X = A · Z = B · Enter = Start · 右Shift = Select；玩家2 = W A S D 移动 · K = A · J = B · I = Start · U = Select。都可以改：大厅点「按键设置」，游戏里点「按键」。

    手机：进入游戏后屏幕下方会出现虚拟手柄，横屏更好按。

    存档：游戏面板里的「存档」把当前进度存进本机浏览器，换设备/清缓存就没了；它和游戏自带的电池存档是两回事。

    卡带架：导入的 ROM 保存在你本机浏览器的 IndexedDB 里（只在这台设备上），换设备/清浏览器数据就没了；不占用网站空间，也不会上传。

    版权：内置的 Falling 由 tragicmuffin 以 MIT 协议开源（Copyright © 2018 tragicmuffin），模拟器 jsnes 1.2.1 为 Apache-2.0。本站不含任何商业 ROM；你载入的 ROM 由你自己提供，只在浏览器内存里跑，不上传。

    按键设置

    点一下按键框，再按键盘上想用的键即可改键（按 Esc 取消）。同一个键只能绑一个位置，重复绑定会自动从原位置挪过来。设置保存在本机浏览器。
