# 像素屋 · PIXEL HOUSE

> 打发无聊的像素风单页站 —— 32 款小游戏 + 32 个互动玩具 + 每日内容全家桶。
> 纯原生 HTML/CSS/JS，零构建、零框架、零外部依赖，一个 index.html 打天下。

🔗 **线上**：https://weiyan06.github.io/wuliao/ ｜ 🪞 国内镜像：https://gitee.com/weiyan06/wuliao/

## 🚀 使用

- 直接访问线上地址，或本地双击 `index.html`（file:// 也能跑）
- 所有进度（收藏、打卡、最佳分）存在浏览器 localStorage，不上传任何数据
- 首屏仅约 102KB（gzip）；唐诗 1.7MB 数据首次进诗词 tab 才加载

## 📁 项目结构

```
index.html          页面壳：全部 HTML/CSS/逻辑（v3.0 后仅 ~350KB）
data/site.js        随机内容/练嘴/菜谱/故事/单词 数据
data/movies.js      电影片库 95 部
data/tang.js        唐诗数据 320 首（懒加载）
AGENTS.md           AI 开发工具说明书（架构/流程/坑位）
```

## 📦 数据来源与口径

- **唐诗**：公开古籍数据整理，简体全文含「一作」注
- **单词**：[skywind3000/ECDICT](https://github.com/skywind3000/ECDICT) 开源词库（CET4 核心 220 词），例句用法为手写
- **电影评分**：豆瓣公开评分，精选片目人工整理，如有出入以豆瓣页面为准
- **菜谱 / 故事 / 练嘴 / 笑话**：全部手写创作
- 不接任何外部 API，离线可用
